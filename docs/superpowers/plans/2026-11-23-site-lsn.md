# Site LSN — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire et mettre en ligne le site statique de Labs Startup Nation (accueil, Tech Watch avec archive et RSS, formulaire de proposition, pages Projects/About/Join/légales) à partir de la maquette validée.

**Architecture:** Site Astro statique. Chaque numéro de la Tech Watch est un fichier JSON validé par un schéma zod au build. Le formulaire écrit directement dans une table Supabase protégée par RLS (insertion seule). Un seul script client anime tous les rayons tramés de la page. Hébergement Vercel, une prévisualisation par pull request.

**Tech Stack:** Astro (dernière version stable, ≥ 5, collections avec loader `glob`), TypeScript strict, `@astrojs/sitemap`, `@astrojs/rss`, `@fontsource/*`, `@supabase/supabase-js`, Vitest (unitaires), Playwright + `@axe-core/playwright` (bout en bout), Supabase CLI (migrations, base locale).

**Spec:** `site/PLAN.md` (plan V1 validé). Sources de valeurs : maquette https://claude.ai/artifact/8WnPxiazUkiVZBZK9aqSAs, design system https://claude.ai/artifact/MVC91Z93UcS1C7Rr6RyHsb, newsletter S44 https://claude.ai/artifact/LyYoZSSfpFJumsxEX9Gftd.

**Racine du dépôt :** `site/` (devient le dépôt `lsn-site`). Tous les chemins ci-dessous sont relatifs à `site/`.

## Global Constraints

- Hypothèses de la spec retenues : H1 Astro, H2 un JSON par numéro, H3 Supabase, H5 Vercel. **H4 remplacée (décision du 23/11/2026)** : site en **anglais et français**, la langue suit celle du navigateur.
- **Langues** : `en` (par défaut) et `fr`. Une URL par langue : toutes les pages vivent sous `src/pages/[lang]/` et toutes les URL de ce plan s'entendent préfixées (`/en/tech-watch`, `/fr/tech-watch`…). `/` redirige selon `Accept-Language` (règles `has` de `vercel.json`, avec un repli côté client qui lit `navigator.languages`) : `fr*` → `/fr/`, tout le reste → `/en/`. Sélecteur EN/FR dans l'en-tête, qui garde la page courante. Balises `<link rel="alternate" hreflang>` (`en`, `fr`, `x-default` → `/en/…`). `<html lang>` = langue de la page.
- **Contenu de la Tech Watch** : les numéros restent rédigés en anglais seulement. Sur `/fr/tech-watch/…`, l'interface est en français et une mention indique « Ce numéro est rédigé en anglais. » Le flux `/rss.xml` reste unique, sans préfixe.
- Node : `.nvmrc` = `24` et `engines.node` = `>=24` (la spec demande « 20 LTS ou plus récent »).
- Textes de l'interface dans `src/i18n/ui.ts`, jamais en dur dans les composants. Ce plan et la doc interne sont en français.
- Polices auto-hébergées uniquement (`@fontsource/unbounded` 500/600/700/800, `@fontsource/outfit` 400/500/600/700, `@fontsource/dm-mono` 400/500). Aucune requête vers `fonts.googleapis.com` ou `fonts.gstatic.com`.
- Aucun cookie, aucun traceur ; la mesure d'audience est sans cookies (Vercel Web Analytics).
- Les tokens couleur reprennent à l'identique le `:root` de la maquette, y compris `--smoke: rgba(31,20,9,.62)`, `--smoke-ink: #FFFBF2`, `--smoke-ink-soft: #FAF3E6`. Thème sombre « Nuit chaude » sous `@media (prefers-color-scheme: dark)` avec les valeurs sombres de la maquette.
- Gouttières latérales : `max(16px, env(safe-area-inset-left/right))`. Aucun défilement horizontal à 320 px de large.
- Focus : `outline: 2px solid var(--focus); outline-offset: 2px; box-shadow: 0 0 0 6px var(--focus-halo)`.
- Canvas des rayons `aria-hidden="true"` ; tout le texte reste dans le HTML.
- Seules `PUBLIC_SUPABASE_URL` et `PUBLIC_SUPABASE_ANON_KEY` vont côté client. La clé `service_role` n'apparaît jamais dans le dépôt ni dans Vercel.
- Les URL de page (sous `/en` et `/fr`) : `/`, `/tech-watch`, `/tech-watch/AAAA-MM-JJ`, `/propose`, `/projects`, `/about`, `/join`, `/legal`, `/privacy` ; plus `/rss.xml` à la racine. Pas d'ancres `#` pour naviguer.
- Comptes (GitHub, Supabase, registrar) au nom de LSN, deux administrateurs minimum. **Vercel : un seul compte gratuit (Hobby) au nom de LSN** (adresse e-mail partagée de l'association), sans équipe Vercel.
- **Rayon et souris** : sur le grand rayon en haut de chaque page uniquement, un léger glissement du dégradé qui suit le pointeur, seulement si `(hover: hover) and (pointer: fine)` et sans `prefers-reduced-motion: reduce`. Les cartes ne réagissent pas.

## Review Focus

1. **Décalage de fuseau sur les dates** : un numéro daté `2026-10-26` doit s'afficher « 26 Oct 2026 » quel que soit le fuseau de la machine de build ou du navigateur, jamais « 25 Oct ». → test dans la tâche 5 (`formatIssueDate` avec `TZ=America/Los_Angeles`).
2. **Numéro incomplet** : un numéro sans `note`, sans `pdf`, avec `agenda: []` ou une section sans article s'affiche sans titre de section vide ni lien mort. → test dans la tâche 6 (fixture `minimal`).
3. **Envoi du formulaire raté ou doublé** : réseau coupé ou Supabase en erreur → message d'erreur qui dit quoi faire, champs conservés ; double clic → une seule insertion. → tests dans la tâche 8.
4. **Contenu long sur petit écran** : titre très long, URL sans espace, chiffre comme `$92.3B` dans une carte à 320 px → pas de défilement horizontal. → test dans la tâche 10 (toutes les pages à 320 px).
5. **« Réduire les animations » laisse un canvas vide** : avec `prefers-reduced-motion: reduce`, chaque rayon doit être dessiné une fois (image figée), pas laissé transparent. → test dans la tâche 3.
